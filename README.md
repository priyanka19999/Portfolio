Welcome to my personal developer portfolio, a modern and high-performance web application designed to showcase my frontend engineering projects, professional experience, and technical capabilities. Built with React 19, Tailwind CSS, and Framer Motion, it features an executive dark aesthetic, fluid micro-interactions, and functional interactive project sandboxes.

## ✨ Features

- **Architectural Dark Design:** A calm, executive monochrome dark theme built with glassmorphic docks, ambient spotlights, and smooth 4° 3D perspective tilt effects.

- **Interactive Project Sandboxes:** Integrated live simulators that let users test real features—including an AI image generator, surplus food rescue logistics with PIN verification, and real-time blogging.

- **Protected View-Only Resume:** Built-in resume viewer modal engineered with print and download protection (disables unauthorized copying, intercepts `Ctrl+P`, and displays a security restriction splash).

- **Native Web Audio Synthesis:** Procedural sound design powered directly by the browser's Web Audio API for tactile click and modal feedback, with a global mute toggle.

- **Interactive Contact & Connect:** Direct message dispatch with client-side validation, one-click email copy, and celebratory particle animations.

## Tech Stack
  - React.js (v19)
  - Vite
  - Tailwind CSS (Styling)
  - Framer Motion (Animations)
  - Redux Toolkit (State Management)
  - Aceternity UI & ShadCN UI
  - Lucide React (Icons)
  - Web Audio API (Synthesizer)
